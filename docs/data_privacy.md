# Data privacy

This project uses restricted longitudinal health-survey data. Participant-level records, direct identifiers, row-level outputs, and any files covered by the data-use agreement are excluded from version control.

The public portfolio version includes only:

- reusable R analysis code with relative local paths;
- a data-access guide rather than the underlying files;
- high-level methodology; and
- aggregate findings appropriate for professional presentation.

All analysis inputs are expected under `data/private/`, which is ignored by Git. Access, retention, and any reuse of the underlying data remain subject to the governing approval and agreement.
