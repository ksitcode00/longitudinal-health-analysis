# Data access

The participant-level survey data for this study are restricted under the project data-use agreement and are **not included** in this repository.

To reproduce the local analysis in an approved environment, place the authorized files in `data/private/`:

- `cleaned_study_data.csv` — longitudinal survey extract
- `symptom_severity_scores.csv` — symptom-severity scoring file

The directory is ignored by Git. This public repository contains only the analysis workflow, documentation, and aggregate portfolio figures.
